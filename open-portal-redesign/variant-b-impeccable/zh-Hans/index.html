核心产品

三大核心产品， 一套对接接口。

三大核心产品端到端覆盖关键旅游业务流程。逐行对比，然后从你的系统最先需要的那一个开始。

G-Link

酒店接口

全球主要酒店库存，行业级数据准确度。
覆盖范围

全球主要酒店库存，完整流程涵盖实时查询、试单、预订与取消。

业务流程

查询 → 试单 → 预订 → 取消

对接接口
  • POST/{v}/hotel/search
  • GET/{v}/hotel/rates/calendar
  • GET/{v}/hotel/rooms/{id}
  • POST/{v}/hotel/bookings

仅为结构示意，非正式接口签名。

能力
查询接口 预订管理 价格日历 房型详情

F-Link

机票接口

覆盖国内与国际航司的直连舱位库存。
覆盖范围

覆盖国内与国际航司的直连舱位库存，支持 BSP，涵盖查询、定价、出票、退票与改期。

业务流程

查询 → 定价 → 出票 → 退改

对接接口
  • POST/{v}/flight/search
  • GET/{v}/flight/fares
  • POST/{v}/flight/orders
  • GET/{v}/flight/refund-rules

仅为结构示意，非正式接口签名。

能力
航班查询 实时运价 订单管理 退改规则
从 F-Link 开始
TMC

差旅管理接口

面向企业差旅项目的成熟接口化差旅管理层。
覆盖范围

成熟的接口化差旅管理能力。快速上线自有品牌的企业差旅服务，支持深度定制，无需从零搭建。

业务流程

差旅政策 → 审批 → 费用 → 结算

对接接口
  • GET/{v}/tmc/policies
  • POST/{v}/tmc/approvals
  • GET/{v}/tmc/expense-rules
  • GET/{v}/tmc/reports/billing

仅为结构示意，非正式接口签名。

能力
企业管控 费用规则 结算报表 审批流
