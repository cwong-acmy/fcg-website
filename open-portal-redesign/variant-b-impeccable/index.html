Three Core Products, One Integration Surface.

Three core products cover the key travel workflows end to end. Compare them row by row, then start with the one your stack needs first.

G-Link

Hotel API

Major global hotel inventory with industry-grade data accuracy.
Coverage

Major global hotel inventory, with the full workflow from real-time search and test booking through to reservation and cancellation.

Workflow

search → test booking → reserve → cancel

Integration surface

F-Link

Flight API

Direct airline seat inventory across domestic and international carriers.
Coverage

Direct airline seat inventory for domestic and international carriers, with BSP support, covering search, pricing, ticketing, refunds and changes.

Workflow

search → price → ticket → refund / change

Integration surface
  • POST/{v}/flight/search
  • GET/{v}/flight/fares
  • POST/{v}/flight/orders
  • GET/{v}/flight/refund-rules

Illustrative shape, not a published signature.

Capabilities
Flight search Live fares Order management Refund rules
Start with F-Link
TMC

Travel Management API

A mature, API-based travel management layer for enterprise programmes.
Coverage

Mature API-based travel management. Launch a branded enterprise travel service quickly, with deep customisation and no need to build from scratch.

Workflow

policy → approval → expense → billing

Integration surface
  • GET/{v}/tmc/policies
  • POST/{v}/tmc/approvals
  • GET/{v}/tmc/expense-rules
  • GET/{v}/tmc/reports/billing

Illustrative shape, not a published signature.

Capabilities
Enterprise control Expense rules Billing reports Approval flow
