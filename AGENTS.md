# FCG Website - Codex Notes

This is the main FCG Website project folder. It contains the website pages, reusable components, assets, references, drafts, outputs, and design archive.

## Project Areas

- Website HTML pages live at the project root.
- Reusable page components live in `components/`.
- Active drafts live in `drafts/`.
- Working versions live in `working-versions/`.
- Reference material currently lives in `reference/`; new research should go in `research/`.
- Design history and visual references live in `design-archive/` and `design/`.
- Images and other site assets live in `assets/`.
- Generated deliverables live in `outputs/`.
- Formal proposals and client-facing deliverables should go in `proposals/`.
- Superseded or uncertain files should go in `archive/` only after Crystal approves.

## Working Rules

- Do not move or consolidate the separate `FCG Website - ...` folders without Crystal approving a move plan first.
- Do not delete old page versions; archive them after review.
- Keep edits small and explain visual/content changes in plain English.
- Do not start a local preview unless Crystal explicitly asks.
