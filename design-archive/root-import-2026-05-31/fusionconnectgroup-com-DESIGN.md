# Design System: FCG Group - Travel Infrastructure

> Extracted from [https://www.fusionconnectgroup.com/](https://www.fusionconnectgroup.com/) by brandmd

## 1. Visual Theme & Atmosphere

**Overall mood:** Balanced and professional

**Density:** Moderate. The layout uses a varied spacing scale.

**Shape language:** Rounded, friendly aesthetic with generous corner radii.

**Depth:** Uses 5 shadow styles for layering and elevation.

## 2. Color Palette & Roles

- **Light Muted Blue** (`#F7F8FA`) — Page background
- **Dark Blue** (`#111827`) — Dark background / footer
- **Orange** (`#F97316`) — Accent background
- **Muted Blue** (`#9CA3AF`) — Secondary background
- **Dark gray** (`#71717A`) — Secondary background
- **Dark Muted Blue** (`#0F1114`) — Primary text
- **Dark Muted Blue** (`#6B7280`) — Secondary text
- **White** (`#FFFFFF`) — Light text (on dark)
- **Light Muted Blue** (`#E5E7EB`) — Divider / border
- **Black** (`#0000001F`) — Divider / border

## 3. Typography Rules

**Primary font:** Inter

**Fonts by role:**
- Headings: Inter
- Body: Inter

**Type scale:**
- Headings: 24px, 30px, 48px, 60px, 92px
- Body / UI: 14px, 15px, 16px, 18px, 20px
- Captions / Small: 8px, 9px, 10px, 11.52px, 12px

**Weights in use:** 300, 400, 500, 600, 700

**Line heights:** 24px, 16px, 20px, 28px, 17.28px, 15px, 12px, 13.5px, 99.36px, 36px

**Letter spacing:** 0.8px, -0.36px

## 4. Component Stylings

### Buttons
- Background: `rgb(17, 24, 39)`
- Text color: `rgb(255, 255, 255)`
- Padding: 16px 32px 16px 32px
- Corner radius: 9999px
- Font: 14px, weight 500

### Cards
- Shadow: `rgba(15, 17, 20, 0.09) 0px 22px 70px 0px`
- Padding: 32px 32px 32px 32px

### Inputs
- Border color: `#E5E7EB`

## 5. Layout Principles

**Spacing scale:** 1px, 3px, 4px, 8px, 12px, 16px, 24px, 32px

**Base unit:** 4px grid (values are mostly multiples of 4).

**Border radii:** 2px, 4px, 6px, 12px, 16px, 24px, 32px, 9999px

## 6. Guidelines

### Do
- Use 4px grid for all spacing
- Use `#F97316` for primary actions and CTAs
- Use `Inter` as the primary typeface

### Don't
- Don't introduce colors outside the palette above
- Don't mix fonts. Use Inter everywhere
- Don't use inline styles when the design system covers the pattern
- Don't use border-radius values outside: 2px, 4px, 6px, 12px, 16px, 24px, 32px, 9999px
