# FCG Website - Claude Notes

This is the main FCG Website project folder. Use this file to stay oriented before editing website pages, drafts, references, or design files.

## Start Here

1. Read `README.md`.
2. Check `reference/` for brand, positioning, product, and design context.
3. Check `drafts/` and `working-versions/` before changing visible website content.

## Project Areas

- Website pages are at the project root.
- Components are in `components/`.
- Current and previous drafts are in `drafts/` and `working-versions/`.
- Research and source context should go in `research/`.
- Proposals and formal deliverables should go in `proposals/`.
- Design files and references should go in `design/` or `design-archive/`.
- Generated outputs should go in `outputs/`.
- Archive only after Crystal approves.

## Working Rules

- Do not move or merge the `FCG Website - ...` folders yet.
- Do not delete old versions.
- Do not open or start a preview unless Crystal asks.
- Keep summaries clear and non-technical.
