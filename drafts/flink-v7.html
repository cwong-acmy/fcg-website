Air · Paths

Where F‑Link fits.

F‑Link is not a global breadth play. It fits China-routed flows, APAC exposure, and TMCs already using G‑Link.

Path A · Travelsky / GDS

Where global air APIs hand off

Travelsky anchors Chinese air ticket distribution. F‑Link connects through that path while keeping FCG's CBT and the broader GDS environment consistent.

Travelsky & Sabre live · more GDS on roadmap · Unified CBT consumes F‑Link directly · Internal TC operators routed through F‑Link.

Path B · China outbound & APAC

Routes anchored in Asia

China outbound and intra-APAC routes are why F‑Link exists. Travelsky, local ticketing norms, and regional commercial relationships are hard to retrofit from outside.

China domestic + outbound · APAC routes with regional carriers · Local payment, currency, ticketing native.

Path C · Co-routed with G‑Link

One vendor for hotel and air

For TMCs already integrating G‑Link, F‑Link is the simplest path to single-vendor coverage. Same Open Platform, same developer surface, same BMS for air and hotel operations.

Single commercial relationship · Shared BMS · Same three doors as G‑Link.

Path D · Air partners roadmap

Clear about what is next

Additional air partners are added as they ship, with China-routed demand first and broader regional depth second.

MCP version exposed, next versioning TBA · Documented as shipped, no promised inventory · Default air layer for AI booking agents in Asia.

Integration

Skills, API, or SDK. Three ways into F‑Link.

Same Open Platform as G‑Link. Skills is the fastest start; the F‑Link MCP surface is live today, with API and SDK support alongside it.

01

Skills · AI-native

Paste a Skills command into your AI tool. Describe the air search and booking flow in plain English. The model reads the docs and drafts the integration.

/skill fcg-flink
02

API · MCP version

The F‑Link MCP surface is live today. Traditional REST remains available for teams that need full control.

POST /flink/air/search
03

SDK · Managed surface

Typed primitives for air search, pricing, booking, and ticketing. Less boilerplate for stacks already running G‑Link's SDK.

npm i @fcg/flink
