Scope · So you don't waste a demo slot

F-Link isn't trying to cover every route.

A fast disqualifier before you book time. F-Link earns its weight where global air APIs hand off, and as the air layer for TMCs already on G-Link. Everywhere else, we'll be honest about it.

F-Link is built for
  • TMCs with Asia or China-route exposure: domestic, outbound, or APAC with Chinese carriers.
  • TMCs already on G-Link who want air through the same vendor, contract, and mid-office.
  • Teams building AI booking agents that need Travelsky-routed air via the MCP API surface.
  • TMCs where Travelsky access is the gap their current global API can't close.
F-Link is not built for
  • Global all-route coverage as the headline. If China and APAC aren't in your route mix, F-Link won't be the biggest lever you can pull today.
  • Leisure-first OTAs. F-Link routes corporate-travel-grade air. Wrong shape of customer.
  • US-domestic-only TMCs with no Asia exposure. Your existing global air API will outperform us on those lanes.
  • "Replace everything" projects. F-Link augments. Most TMCs multiplex air APIs, that's how we expect to be deployed.
