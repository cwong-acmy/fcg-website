How the network works

Decentralized & autonomous

Each hub runs the full system on its own — no central server, no master hub.

Shares only what's needed

Hubs exchange only what a booking needs — never bulk data — so it stays in its home region.

Resilient by design

If one hub goes offline, the rest keep running — no single system failure can take it all down.

Scale on demand

Add a hub in any new region or country — it joins automatically, with no central rebuild.
